# 内置动态特效素材

`01_star_sparkles.mp4` 是本项目使用 FFmpeg 程序化生成的原创黑底星光素材，不依赖外部下载或第三方版权素材。早期近似静态的飘雪、流星和扫光素材已从随机素材池移除。

扩展素材中的粒子纹理来自 Kenney Particle Pack，法术动画来自 OpenGameArt 的 2D Spell Effects；两者均为 CC0。具体来源、作者和许可证见 `SOURCES.md`。扩展素材仍会被转换为黑底动态 MP4，适配本工具统一抠像。

在 GUI 中使用时请选择：

- 启用随机动态特效：开启
- 随机特效目录：本目录
- 素材背景：黑色背景
- 显示区域：全屏

“随机时间出现”会按每分钟频率插入不同效果；“全程循环”只会随机选择其中一个素材并循环覆盖整段视频。
